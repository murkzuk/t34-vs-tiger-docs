# _archive/

Non-destructive parking for files that don't belong in the live tree but are kept
for history rather than deleted.

| Path | Origin | Why it's here |
|---|---|---|
| `TvT/temp.md` | `TvT/temp.md` | Placeholder note ("will be the home of..."), never implemented |
| `TvTZW/temp.md` | `TvTZW/temp.md` | Placeholder note for the ZW scripts; real ZW content lives in `concatenate scripts/ALL_ZW_SCRIPTS/` |

Note: the Maya export experiments (`Sky_*.script`, `Test_House*.script`, etc.) are
archived separately in `TvT/archive/`, kept there because they sit inside the
`TvT/` mirror of the live game install.

Nothing here is referenced by the game or the build. Safe to keep, do not delete
(that's the point of the folder).
