# Could REDUX become an official release? — PARKED, Phase 5 question

Recorded 2026-08-25 from a ChatGPT conversation the user shared so it would not
be lost. **Nothing here is being acted on.** It belongs at the end of the
ladder, not now — see [[THE_PLAN]].

## The user's question

> *"I honestly think there is a market for TvT Redux, but it's finding who owns
> the source code. If I was to approach MicroProse or some such, I'm sure they
> could find it, but I don't want to do that through a third party."*

## What holds up

**Don't chase the rights now.** Finish phases 1-4 first, then the conversation
is "here is a working rebuilt game" rather than "here is an idea". That is
straightforwardly right and matches the plan already in place.

**Ask who owns the IP, not for the source.** "Who currently controls the
intellectual property and development assets" is a reasonable question. "Can I
have your source code" is an alarming one. Sequence matters.

**Preserve provenance.** The dated GitHub history, the notes, the before/after
measurements. Not for legal reasons — so that "what exactly have you done?" has
a chronological answer. This is already happening by accident; worth doing on
purpose.

**The audience is real but small.** Steel Fury, Graviteam, Combat Mission
players. Small is not zero.

## What is probably WRONG in that advice

**The JoWooD → Nordic → THQ Nordic rights trail is very likely the wrong
chain for this title.** That acquisition is real, but TvT's actual lineage is:

```
G5 Software (developer, Russian)
  -> IDDK Group (Russian publisher)
  -> Lighthouse Interactive (Western publisher) -- went BANKRUPT during release
```

JoWooD does not obviously appear in it. Following that trail could waste months
and approach an entirely uninvolved company. **Verify the chain before acting on
it.** MicroProse is also not the right starting point and never published it.

**It also does not know two things the user has already established:**

1. **A preservation copy is already on the Internet Archive, uploaded
   anonymously by the user.** That materially changes the posture of any later
   approach and should be thought about before contacting anyone.
2. The user's own prior conclusion: *"zw is dead and g5 dont exist, no owners of
   the code"* — which may or may not survive checking, but is a different
   starting assumption from ChatGPT's.

## The complication nobody raised

**ZeeWolf 2015 is third-party payware.** A meaningful amount of this month's
work is in the ZW build. Anything commercial would have to separate REDUX's own
work from ZW content cleanly. Not a blocker — but it is a real line to keep
visible, and it is easier to keep separate now than to untangle later.

## Where this sits

**Phase 5, alongside the Patton's Best decision.** Both are "decide once the
game is good enough", and both would use the same gate:

1. the game is technically good enough to show someone
2. there is enough content to demonstrate the proposition
3. the actual IP owner has been established

Do not start any of it before Phase 4 closes.
